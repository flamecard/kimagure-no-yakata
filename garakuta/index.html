気まぐれサムネ工房

動画投稿サイトのサムネイルや，A4サイズのポスター作りにどうぞ！
他のサイズへの対応も，適宜行う予定です．

編集画面（v1.9.1）．
画像をクリックすると拡大できます．

主な機能

  • HD・A4の縦横とTCG縦型サイズでサムネイルやポスターを制作．
  • 文字の装飾・画像の配置・レイヤーの並べ替えに対応．
    プレビュー上で文字を直接編集できます．
    Alt＋ドラッグでパーツをトリミングできます．
  • PNG・JPEG・レイヤー付きPSDへの書き出し．
    PSD内の文字は画像レイヤーです．
    PSDの読み込みは未対応です．
  • 編集データの保存・読み込みに対応．
    素材追加時も配置済みのパーツを維持します．
  • インストールと画像編集はオフラインで利用できます．
対応OS
Windows 10／11（Intel・AMD 64bit）
ライセンス
無料で利用できます．
商用利用もOKです．
ソフト本体の再配布は禁止です．
クレジット表記は任意ですが，記載していただけると嬉しいです．
表記例：気まぐれサムネ工房（気まぐれの館）

KomaCut Next

動画・画像・音声を組み合わせて編集できる，
Windows用の無料動画編集ソフトです．
横長の動画から縦長のショート動画まで制作できます．

主な機能

  • 複数トラックの編集，
    カット・リップル削除，
    ドラッグ配置，
    音声波形と無音の自動カット．
  • テロップの直接編集，
    縦書き，
    端末のフォント選択，
    画像の移動・サイズ調整・切り抜き．
    横位置・縦位置もスライダーで調整．
  • 雑音低減・音量調整，
    音声フェード，
    映像のつなぎ，
    速度変更，
    グリーンバックの切り抜き．
  • 位置・サイズ・不透明度・切り抜き・音量のキーフレーム．
  • 複数タイムライン，
    別ウインドウのプレビュー，
    画質の切り替え，
    軽量プレビューの準備と再利用，
    作業環境の保存．
  • 横長1920×1080／縦長1080×1920のMP4を60fpsで書き出し．
    完了通知にも対応．
対応OS
Windows 10／11（Intel・AMD 64bit）．
.NET Framework 4.8．
ライセンス
無料で利用できます．
商用利用もOKです．

クレジット表記は任意です．
表記例：KomaCut（気まぐれの館）．
外部ツールには提供元のライセンスが適用されます．

気まぐれQR

URLをQRコードに変換する，Windows専用の小さなソフトです．
ブラウザーを開かず，ネット接続なしで作成・保存できます．

主な機能

  • URLを入力してQRコードを作成．
  • PNG・SVG形式で保存．
  • 画像サイズは512・1024・2048・4096pxから選択できます．
  • 汚れや欠けへの強さを4段階で調整できます．
  • インストール・ログイン不要．
    作成と保存はオフラインで利用できます．

気まぐれの大会室

TCGの個人戦を，受付から優勝決定まで管理できる大会運営ツールです．
インストール不要で，スマホ・PCのブラウザから利用できます．

主な機能

  • 定員2〜32人．
    先着順・抽選受付とキャンセル待ちの繰り上げに対応．
  • スイスドロー，タイブレイク，プレーオフの組み合わせを管理．
    自動設定では16人未満は全勝者が1人になるまで，16人はトップ4，17〜32人はトップ8です．
  • 参加者のスマホで出席確認・結果報告・相手の承認．
    スマホがない方は主催者がゲストとして登録・代行できます．
  • 名前だけの登録，またはデッキリスト必須を選択．
    デッキログ対応のブシロードTCGと，ポケカ公式デッキのURL・コード提出に対応します．
    リストは本人と主催者だけが閲覧でき，主催者が公式ページで確認します．
  • 順位表・大会記録をメモ帳で読めるテキスト形式で保存．
対応環境
スマホ・PCのブラウザ（インターネット接続が必要）
利用方法
主催者はChatGPTでログインして大会を作成．
参加者には大会URLまたは大会コードを共有してください．
