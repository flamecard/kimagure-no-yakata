# 気まぐれQR ホーム画面版

MacやAppleの署名設定を使わず，iPhone / Androidのホーム画面から利用できるPWAです．
初回だけネット接続が必要です．ホーム画面への追加後も，一度オンラインで起動して「オフライン利用の準備完了」を確認してください．

- URLの正規化・QR生成・PNG / SVG作成は端末内で完結します．
- QRエンジン，画面，アイコン，ライセンスを同じディレクトリに同梱しています．CDN依存はありません．
- `sw.js` の登録範囲はこのディレクトリ内だけです．他のサイトページの通信には干渉しません．
- 必須ファイルをすべて保存できたときだけ，準備完了と表示します．
- 更新はユーザーの操作後に適用します．入力中の場合は消去前に確認します．
- 入力URLの履歴やQR画像を自動保存・送信しません．オフライン用キャッシュに入るのはアプリ本体だけです．
- ファイル共有に対応した端末ではPNGを共有メニューへ渡します．未対応時は画像長押しやPNG / SVGダウンロードを利用できます．

データ削除・容量不足などでブラウザーの保存データが失われた場合は，オンラインで再準備が必要です．
PNG / SVGを端末内に保存する操作はオフラインで利用できます．リンク先やクラウドへのアクセスには通信が必要です．

## 検証（2026-10-24）

Linux上の実際のChromeで，ネットワークを遮断して次を確認しました．

- 事前準備後にタブを閉じ，新しいタブでアプリを開き直せること．
- 5種類のURL × 4段階の誤り訂正でQRを生成し，PNG / SVGの40ファイルを保存．独立したデコーダーで内容一致を確認．
- URL入力・生成時に外部へのリクエストが発生しないこと．
- 無効URL・容量超過で保存ボタンが無効になること．
- 幅320 / 375 / 393 / 430 / 768 / 1280pxで横方向に画面がはみ出さないこと．
- オフライン用の保存データが欠けた場合，準備完了表示を取り消すこと．オンラインでの再準備が成功すること．
- 初回ダウンロードが中断された場合に，準備完了と表示しないこと．

iPhone実機でのホーム画面起動と，iOSの共有・写真保存メニューは未検証です．

更新するときは `sw.js` の `VERSION` を変更してください．同じバージョンのままファイルを置き換えると，既存端末が古いキャッシュを使い続けます．
